**GrillMe**

AI powered mock interviews based on your resume and the role you want.

GrillMe is an interactive web app that generates personalized mock interviews for software engineering and product management roles. Users upload their resume, choose the type of role, pick behavioral or technical questions, then talk to an AI interviewer that drills them in real time.

This project is built to help students and early career devs practice interviews in a more realistic and customized way.
